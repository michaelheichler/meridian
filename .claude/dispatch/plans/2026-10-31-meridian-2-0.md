## Project Summary

LBWC is a Claude Code plugin for planning, building, QA and UAT with human-owned direction. This plan stabilizes it, cuts the test suite below 500 real tests, lowers token cost, adds automatic session handover and a structured feedback card, and renames the product to Meridian as release 2.0.0.

## Shared Understanding (owner decisions, 2026-10-31)

These decisions are final. Every task in this plan follows them.

1. **No feature is ever cut.** Slimming means faster, more precise, and cheaper in tokens. A task that removes a user-visible capability is wrong.
2. **Nobody uses the word "bearing"** in names, commands, docs, UI text or replies.
3. **Audience.** The owner alone at first. Keep the repo clean. Compatibility layers and licensing work are low priority.
4. **Premium means** good feedback, clean output, clean interaction with Claude Code, and agents that work precisely.
5. **Order.** Stabilize first, then tests, then tokens and hooks, then handover and feedback, then the rename, then release.
6. **Hook failure policy.** Only an explicit deny blocks a tool call. A crashing guard lets the call run and prints a one-line warning.
7. **Runtime.** Keep bash. Add a bash version guard. Port only the hook dispatcher to Python.
8. **Tests.** Under 500 tests in total, no hollow tests. Coverage target is 90% or more of lines in `scripts/`, plus 100% of the allow and deny branches in hooks and gates. Measure coverage before and after consolidation.
9. **Token work.** Per-command `model:` frontmatter, split `verify`, `debug` and `init` into small cores plus on-demand references, one Python hook dispatcher, real context usage instead of bytes / 4. No native skills. The forced `skills-bundle` Read per role stays, because the read is how a role learns its job.
10. **Handover.** `EXPLORER-JOURNAL.md` in the planning dir. Append-only. When the file passes 8 KB, the writer moves the older entries to `journal-archive/` and deletes nothing. Writers are PreCompact, pause, and the end of each phase. Resume reads the journal plus a git delta and checks HEAD for staleness.
11. **Feedback card.** Every step ends with the same structured card. No hard line cap.
12. **Worker contract.** Workers return a fixed schema (status, changed files, commands run with exit codes, open questions). The main session re-runs the proof before it reports done.
13. **Rename.** Everything becomes Meridian. `/lbwc:vibe` becomes `/meridian:transit`, `/lbwc:init` becomes `/meridian:init`, the other commands keep their verbs. `.lbwc-planning/` becomes `.meridian/`, `LBWC_*` becomes `MERIDIAN_*`. A one-shot migration moves old state. The owner makes the images.
14. **Git.** One branch, `refactor/meridian-2.0`, commits by Michael Heichler <iam@michaelheichler.eu> (repo-local config). Final full test run, commit and push to `main` without a further owner check.
15. **Session workers.** Sonnet at medium effort writes code. Sol at medium effort runs QA. The ADW test writer (`agent-discipline-watcher:adw-test-writer`) on Sonnet 5.5 writes every test. GitNexus explores first, then DeepSeek V4 Flash or Haiku 5.5. Fable never writes code.

## Scope

**In scope.** Groups A to E and FINAL below.

**Out of scope.** New user features, image creation, a docs website, and the unbuilt features from code report risk 7 (logged as open items, not built here).

## Design Decisions

- **Crash policy.** `scripts/hook-wrapper.sh` passes `exit 2` through and turns every other non-zero exit into `exit 1` with a one-line stderr warning. Claude Code treats exit 1 as a non-blocking error. All 63 deny sites in the guards already use `exit 2`, and no guard denies with `exit 1`.
- **Compaction counter.** SessionStart with source `startup` or `clear` resets `.compaction-count`. Sources `compact` and `resume` keep it.
- **Consolidation before the hook rewrite.** The dispatcher in group C lands on a lean, trusted suite.
- **Rename last.** A rename touches 343 files and 5151 lines. Doing it last keeps the earlier diffs reviewable.
- **Coverage tool.** kcov from Homebrew. This machine has neither kcov nor bashcov today.
